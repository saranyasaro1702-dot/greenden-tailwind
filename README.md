# Greenden - Plant Website

A responsive plant website built using **HTML and Tailwind CSS**, designed with a clean and modern user interface.

## Overview

Greenden is a frontend web development project created to practice and demonstrate the use of **Tailwind CSS** for building responsive and visually consistent web interfaces.

The project focuses on responsive layouts, reusable utility classes, navigation, product sections, and modern UI design.

## Features

* Responsive navigation bar
* Modern hero section
* Plant product showcase
* Responsive grid layouts
* About and contact sections
* Mobile-friendly design
* Utility-first styling with Tailwind CSS

## Technologies Used

* **HTML5**
* **Tailwind CSS**
* **JavaScript**

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/saranyasaro1702-dot/greenden-tailwind.git
```

### 2. Navigate to the project

```bash
cd greenden-tailwind
```

### 3. Run the project

Open `index.html` in your browser to view the website.
